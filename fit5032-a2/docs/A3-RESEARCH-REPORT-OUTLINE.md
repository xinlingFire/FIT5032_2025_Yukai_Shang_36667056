## Five strategies to investigate yourself

1. Turn a reproducible error, stack trace and minimum code sample into a diagnosis hypothesis; verify it in browser devtools.
2. Ask for likely causes of asynchronous state or race-condition behaviour; create a focused reproduction before accepting the suggestion.
3. Use AI to explain unfamiliar library error messages, then compare the advice against primary documentation.
4. Ask for test-case ideas at validation boundaries; manually write and run the chosen tests.
5. Request accessibility and edge-case review prompts, then verify the findings using keyboard navigation and browser tooling.

## Evidence and references checklist

- Keep screenshots of each actual prompt, response and subsequent manual modification.
- Explain rejected or inaccurate suggestions, not only successful ones.
- Use at least five IEEE references, including two academic sources; cite original documentation for JavaScript, Vue and Firebase where applicable.
- Add a transparent AI acknowledgement matching the course template.
